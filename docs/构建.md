# 构建与出包

本 fork 不修改上游构建脚本，`scripts/` 与 `setup-deps.*` 均可直接使用。推荐优先走云端，避免在本机维护 Qt 工具链。

## 方式一：GitHub Actions（推荐）

`Build - Windows and macOS` 是手动触发的工作流，产物为便携目录，不含安装器。

```bash
gh workflow run build-win-mac.yml --ref master
gh run list --workflow build-win-mac.yml --limit 3
gh run download <run-id> -n Moonlight-Windows-x64-v120
```

产物：

| Artifact | 说明 |
|---|---|
| `Moonlight-Windows-x64-v120` | x64 便携目录，解压后运行 `Moonlight.exe` |
| `Moonlight-Windows-arm64-v120` | arm64 便携目录 |
| `zDevDbgSyms-Windows-v120` | 调试符号，排障用 |

环境：`windows-2025` + Qt `6.12.1`，构建约 11 分钟。`v120` 是 fork 版本标签，`Moonlight.exe` 的文件版本仍跟上游（6.2.0.0）。

> push 触发的 `build.yml` 带 `cancel-in-progress`，连续推送会互相取消；出包请用手动 dispatch。

## 方式二：本地构建

### Windows

- Qt 6.11 SDK 或更高（安装时选 **MSVC**，不支持 MinGW）
- Visual Studio 2022/2026（Community 即可）
- 7-Zip（只有做安装包时需要）
- Graphics Tools（只有调试构建需要）

```bat
git submodule update --init --recursive
setup-deps.ps1
scripts\build-arch.bat release x64
scripts\generate-bundle.bat
```

### macOS

- Qt 6.11 SDK 或更高
- Xcode 15 或更高
- `create-dmg`（只有做 DMG 时需要）

```bash
git submodule update --init --recursive
./setup-deps.py
scripts/generate-dmg.sh
```

### Linux

- Qt 6（推荐，Qt 5.12+ 也可）、GCC 或 Clang、FFmpeg 4.0+
- Debian/Ubuntu 依赖：

```bash
sudo apt install libegl1-mesa-dev libgl1-mesa-dev libopus-dev libsdl2-dev \
  libsdl2-ttf-dev libssl-dev libavcodec-dev libavformat-dev libswscale-dev \
  libva-dev libvdpau-dev libxkbcommon-dev wayland-protocols libdrm-dev \
  qt6-base-dev qt6-declarative-dev libqt6svg6-dev qt6-wayland
```

```bash
git submodule update --init --recursive
qmake6 moonlight-qt.pro
make release
```

### Steam Link

需要 Steam Link SDK，并设置 `STEAMLINK_SDK_PATH`；受硬件限制最高 1080p60 / 40 Mbps，不支持 HDR。详见上游 README。

## 验证

出包后至少确认：

1. 能启动并显示主机列表
2. 串流中横条出现，`Ctrl+Alt+Shift+B` 可显隐
3. `Ctrl+Alt+Shift+H` 能唤出快捷键帮助
4. 设置页能切换横条开关并持久化
