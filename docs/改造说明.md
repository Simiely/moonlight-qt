# Moonlight PC 改造说明

基于官方 `moonlight-stream/moonlight-qt`（master，提交 `8886485`）修改。
共新增两个功能，均不改动串流协议、编解码逻辑，也不改动剪贴板：

1. **连接质量悬浮窗** —— 串流中贴在画面顶部显示半透明实时质量横条（界面中文，默认开启）
2. **快捷键帮助悬浮窗** —— 串流中按 `Ctrl+Alt+Shift+H` 唤出，列出所有可用快捷键（界面中文）

---

## 1. 功能一：连接质量悬浮窗

串流时贴在画面顶部居中显示一条半透明横条（跟随串流画面定位，双屏不会跑偏），从左到右依次是：

- 分辨率、编码格式、帧率、码率
- 网络延迟（RTT）与抖动，丢包率与抖动丢包率（按数值变色：绿/黄/红）
- 解码耗时、主机处理耗时

行为：

- 仅在**串流中**显示，串流结束自动隐藏
- **默认开启**；设置里可关掉持久开关
- `Ctrl+Alt+Shift+B` 在串流中随时显隐（不受设置开关限制）
- `Ctrl+Alt+Shift+[` / `]` 调节整体大小（0.6x~1.6x），或拖右下角手柄
- 位置固定在画面顶部居中，不提供拖动：串流中鼠标被游戏锁定，拖动本就无法操作
- 不设关闭按钮：串流中鼠标被锁定，按钮点不到，显隐统一交给 `B` 键

## 2. 功能二：快捷键帮助悬浮窗

串流中按 **`Ctrl+Alt+Shift+H`** 唤出一个独立窗口，列出全部快捷键：

键盘（Ctrl+Alt+Shift + 字母）：

| 键 | 功能 |
|----|------|
| Q | 断开会话 |
| Z | 释放/捕获输入 |
| X | 切换全屏 |
| S | 显示/隐藏性能统计 |
| M | 切换鼠标模式 |
| C | 显示鼠标指针（远程桌面模式） |
| D | 最小化窗口 |
| V | 粘贴本地剪贴板文本到主机 |
| L | 切换指针区域锁定 |
| E | 断开并退出 Moonlight |
| K | 切换系统按键捕获 |
| H | 显示/隐藏本帮助 |

手柄：

- `Start+Select+L1+R1` 断开会话
- `Select+L1+R1+X` 性能统计

行为：居中于串流画面显示；再按一次 `H` 关闭。此功能无需设置开关，按键即用。设置页内有完整快捷键面板。

| 文件 | 改动 |

## 4. 编译步骤（Windows）

本机未安装 Qt / MSVC / 7-Zip，无法在此编译。请在装有工具链的机器上：

1. 安装 Qt 6.11+（MSVC 组件）、Visual Studio 2022/2026（MSVC）、7-Zip。
2. 进入仓库根目录，拉取子模块：
   ```
   git submodule update --init --recursive
   ```
3. 安装预构建依赖：
   ```
   .\setup-deps.ps1
   ```
4. 构建：
   ```
   scripts\build-arch.bat release x64
   scripts\generate-bundle.bat
   ```

Linux/macOS 见上游 README（Linux 为 `qmake6 moonlight-qt.pro && make release`，macOS 需 `setup-deps.py` 与 `generate-dmg.sh`）。

## 5. 使用

1. **连接质量窗**：设置 → 勾选 `Show connection quality window while streaming`，开始串流即显示。
2. **快捷键帮助**：串流中直接按 `Ctrl+Alt+Shift+H`，再按一次关闭。
3. 两个窗口都建议主机使用**无边框窗口化**模式；全屏独占游戏可能盖住悬浮窗（Windows 平台层级限制）。

---

## 6. 已知限制与风险提示

- **全屏独占模式**：置顶悬浮窗可能被盖住，属平台限制。
- **未在本机编译验证**：仅做了静态检查（引用一致性、括号结构、线程亲和性、QML 模型语法）。首次编译若有报错，可能是 Qt 版本相关的 `QMetaObject::invokeMethod` functor 重载（Qt 5.10+ 支持，项目要求 5.12+，应无问题）。
- **翻译**：新增文案未加入 `.ts` 翻译文件，会显示英文；可后续用 `lupdate` 更新。
- **快捷键帮助是静态列表**：表中内容按当前官方源码写死。若上游以后改了快捷键绑定，需同步更新 `ShortcutHelpWindow.qml`。
- **剪贴板**：本次未做。标准 Sunshine 的双向剪贴板协议（输入包 `0x55000008` / 控制消息 `0x5505`）仍在未合并 PR（`moonlight-common-c#155`、`Sunshine#5782`）中，且只支持 Linux X11 主机，Windows 主机为空实现。若要双向，需换 Foundation Sunshine 或自行编译打补丁的 Sunshine（主机需 Linux X11）。
